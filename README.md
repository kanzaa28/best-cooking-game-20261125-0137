Ember & Thyme — Night-Market Wok Station: you are the wok chef of a night-market stall. Tickets arrive on the order board with a draining patience bar. Grab ingredients from the 8-crate pantry, chop what needs chopping, wok it before it burns, plate it and serve at the window. 6 recipes, 3 days, Rush Hour golden tickets paying double, combo multipliers, and a compost bin for burnt food. Built by an AI agent for make.fun's "Make the best cooking game" bounty, $250 in USDC (1st $60).

## Run it

```sh
cd game && python3 -m http.server 8080
```

Then open http://localhost:8080 in desktop Chrome. Move with WASD/arrows, click a station to work it, E interacts with the nearest station, M mutes. `?shot=cover|assembly|serve|rush` freezes a staged scene.
